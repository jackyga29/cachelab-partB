1. Idea central: block / tiling

En vez de hacer:

for (i = 0; i < N; i++)
    for (j = 0; j < M; j++)
        B[j][i] = A[i][j];


que causa muchos misses, haces algo así:

for (ii = 0; ii < N; ii += BS)
    for (jj = 0; jj < M; jj += BS)
        for (i = ii; i < ii + BS && i < N; i++)
            for (j = jj; j < jj + BS && j < M; j++)
                B[j][i] = A[i][j];


La clave es elegir un block size (BS) que juegue bien con:

32 bytes por bloque

8 ints por bloque

Y la forma en que A y B mapean al mismo set de caché y se pelean (conflict misses).

2. Caso 32×32 (más fácil)

Aquí el tamaño es pequeño y muy regular. La estrategia típica:

Usar bloques de 8×8.

Dentro del bloque, leer fila por fila de A (bueno para caché).

Escribir columna por columna en B, pero ahora los accesos están “localizados” al bloque, así que se reduce el thrashing.

2.1. ¿Por qué 8×8?

Cada fila del bloque tiene 8 ints → 8 * 4 = 32 bytes = 1 bloque de caché.

Así, leer una fila de 8 ints cabe en un solo bloque de caché.

Al trabajar en un 8×8, reusamos esa línea de caché varias veces de forma local.

2.3. Problema extra: diagonal y conflictos

Cuando el bloque está en la diagonal (es decir, ii == jj), A[i][j] y B[j][i] se mapean al mismo set y mismo bloque en la caché (por cómo están acomodadas), lo que genera muchos conflict misses.

Truco típico:

Si el elemento es diagonal (i == j), no lo escribes inmediatamente en B[i][i].

Lo guardas en una variable temporal y lo escribes hasta el final del bloque.

Ejemplo:

if (i != j) {
    B[j][i] = A[i][j];
} else {
    tmp = A[i][j];
    diag_index = i;
}
...
if (ii == jj) {
    B[diag_index][diag_index] = tmp;
}


Tú tienes que adaptar este truco a tu bloque de 8×8, cuidando no pasarte de las 12 variables int.

char transpose_submit_desc[] = "Transpose submission";

void transpose_submit(int M, int N, int A[N][M], int B[M][N])
{
    int i, j, k, l;
    int block;
    int t0, t1;  /* temporales, también usados para la diagonal */

    /* Caso 1: matriz 32x32 */
    if (M == 32 && N == 32) {
        block = 8;
        for (i = 0; i < N; i += block) {
            for (j = 0; j < M; j += block) {

                if (i != j) {
                    /* Bloques fuera de la diagonal: copiamos 8x8 directo */
                    for (k = i; k < i + block; ++k) {
                        B[j + 0][k] = A[k][j + 0];
                        B[j + 1][k] = A[k][j + 1];
                        B[j + 2][k] = A[k][j + 2];
                        B[j + 3][k] = A[k][j + 3];
                        B[j + 4][k] = A[k][j + 4];
                        B[j + 5][k] = A[k][j + 5];
                        B[j + 6][k] = A[k][j + 6];
                        B[j + 7][k] = A[k][j + 7];
                    }
                } else {
                    /* Bloques en la diagonal: guardamos temporalmente A[k][k] */
                    for (k = i; k < i + block; ++k) {
                        for (l = j; l < j + block; ++l) {
                            if (k != l) {
                                B[l][k] = A[k][l];
                            } else {
                                t0 = A[k][l];  /* valor diagonal */
                                t1 = k;         /* índice diagonal */
                            }
                        }
                        B[t1][t1] = t0;      /* escribimos la diagonal al final de la fila */
                    }
                }
            }
        }
    }

    /* Caso 2: matriz 64x64 */
    else if (M == 64 && N == 64) {
        block = 4;
        for (i = 0; i < N; i += block) {
            for (j = 0; j < M; j += block) {

                if (i != j) {
                    /* Bloques fuera de la diagonal: copiamos 4x4 directo */
                    for (k = i; k < i + block; ++k) {
                        B[j + 0][k] = A[k][j + 0];
                        B[j + 1][k] = A[k][j + 1];
                        B[j + 2][k] = A[k][j + 2];
                        B[j + 3][k] = A[k][j + 3];
                    }
                } else {
                    /* Bloques en la diagonal: mismo truco que antes */
                    for (k = i; k < i + block; ++k) {
                        for (l = j; l < j + block; ++l) {
                            if (k != l) {
                                B[l][k] = A[k][l];
                            } else {
                                t0 = A[k][l];
                                t1 = k;
                            }
                        }
                        B[t1][t1] = t0;
                    }
                }
            }
        }
    }

    /* Caso 3: matriz 61x67 (y en general cualquier otra) */
    else {
        block = 16;   /* tamaño de bloque razonable para el caso rectangular */
        for (i = 0; i < N; i += block) {
            for (j = 0; j < M; j += block) {
                for (k = i; k < N && k < i + block; ++k) {
                    for (l = j; l < M && l < j + block; ++l) {
                        B[l][k] = A[k][l];
                    }
                }
            }
        }
    }
}
